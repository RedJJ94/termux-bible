# Go

The `golang` package in `termux-main` provides the Go toolchain for Android.
Because Go statically compiles most of the runtime, Go is a good fit for
on-device development, and native/cgo code links through the Termux `clang`
wrapper. Version: **3:1.27.1** as of the 2026-09-22 `termux-main` aarch64
index **[version-sensitive]**.

## Install

```sh
pkg install golang
go version && gofmt -version
```

- DEPENDS on `clang` — for cgo, the default CC is the Termux clang wrapper
  (no bundled gcc is needed). RECOMMENDS `resolv-conf` (a DNS resolution
  library for Go binaries; its practical need is `[needs verification]`).
- **`GOROOT` is `$PREFIX/lib/go`**; `$PREFIX/bin/go` and `$PREFIX/bin/gofmt`
  are symlinks into it.
- The build sets `GO_LDSO` to `/system/bin/linker64` (or `linker` on 32-bit),
  adds `-extldflags=-pie`, and disables hardcoded pkg-config paths — cgo
  builds find `pkg-config` at runtime via `PATH`.

## A first module

```sh
mkdir hello && cd hello
go mod init example/hello
cat > main.go <<'EOF'
package main
import "fmt"
func main() { fmt.Println("hello go on termux") }
EOF
go run .
go build              # produces ./hello in the current directory
```

- The default **GOPATH is `$HOME/go`**; module downloads are cached there.
- The default `GOPROXY` is `https://proxy.golang.org,direct`, so `go build`
  of a module with dependencies fetches from the proxy over normal HTTPS. If
  the device is offline, that fails — documented as `[needs verification]`
  for offline builds.
- `GOOS`/`GOARCH` cross-compilation from the phone is standard Go behavior;
  the Termux toolchain is the default build target.

## Native Termux vs. proot

Inside proot-distro, Go comes from the guest's package manager (`apt install
golang-go`) with a glibc toolchain; the runtime and standard library are the
guest's. Keep the two environments' `GOPATH`/caches separate — they are
different toolchains.

## Security notes

- `go build`/`go install` downloads modules from the module proxy and runs
  their build scripts for your target. Only build modules you trust; `go
  mod verify` checks module checksums against `go.sum`.
